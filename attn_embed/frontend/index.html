What are Attention Motifs?

This project investigates structure in the attention mechanisms of large language models. We provide interactive tools to view attention patterns across multiple model architectures.

Key Insight: Attention heads don't just process information randomly—they exhibit systematic, interpretable patterns that can be categorized, visualized, and analyzed to understand how language models work internally.

Pipeline

1. Pattern Extraction

Generate attention patterns from multiple language models using diverse text prompts.

Tools: Pattern Lens Single Pattern View

2. Feature Extraction

Compute handcrafted features from each attention pattern.

Figures: Full Covariance Reduced Covariance

3. Feature Analysis

Normalization and principal component analysis of the table of features.

Tools: Pattern Embedding Visualization
Figures: PCA Analysis PCA Overview

4. Distances between heads

We now have a point cloud in PCA space for each head -- we can compute distances between each cloud to get a distance matrix.

Tools: AttentionPedia
Figures: Head Distances Heatmap

5. Embeddings of heads

Use the distance matrix to get embeddings of heads in a meaningful latent space.

Tools: Head Embedding Visualization Head Embedding Table Classifications Page
Figures: Head Embeddings

Analysis Tools

Explore attention patterns and head behaviors through our interconnected suite of visualization tools:

Head Analysis

Tools for understanding attention heads and their classifications

  • Classifications Page - Browse all head types with links to examples
  • Head Embedding Table - Compare embedding methods with SVG previews
  • Head Embedding Visualization - 3D exploration of head similarities

AttentionPedia

The main interface connecting all analysis tools

  • AttentionPedia - Explore heads with similar patterns and classifications

AttentionPedia serves as the central hub, allowing you to examine any attention head alongside similar heads, view multiple attention patterns side-by-side, and navigate to all other analysis tools.

Pattern Analysis

Tools for examining individual attention patterns

  • Pattern Lens - Compare patterns across models and heads
  • Single Pattern View - Detailed view of individual attention patterns
  • Pattern Embedding Visualization - 3D space of all attention patterns
