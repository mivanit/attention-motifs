Head Embedding Visualizations

Interactive table of head embedding plots generated using different dimensionality reduction methods and parameters.

About These Visualizations

Each plot shows attention heads projected into 2D or 3D space using different embedding methods:

  • ISOMAP: Isometric mapping preserving geodesic distances
  • UMAP: Uniform Manifold Approximation and Projection
  • t-SNE: t-Distributed Stochastic Neighbor Embedding
  • PCA: Principal Component Analysis

Click "View Interactive 3D" to explore the embeddings in an interactive 3D visualization.
