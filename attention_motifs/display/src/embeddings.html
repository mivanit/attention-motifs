Basic Navigation

  • Rotate the plot: Click and drag (if not over a point)
  • Zoom: Scroll wheel or pinch gesture
  • Pan: Right-click and drag (if not over a point)
  • View details: Hover over points

Data Selection and Visualization

  • Select points: Click on points to select by category
  • Copy point data: Right-click on a point
  • Change color grouping: Use "Default color by" dropdown
  • Change selection grouping: Use "Select by" dropdown
  • Clear selection: Click "Clear Selection" button
  • Change colors: Click "Regenerate Colors" button

Visualization Controls

  • Change 3D axes: Use X-Axis, Y-Axis, Z-Axis dropdowns to select different dimensions
  • Adjust appearance: Use "Plot Configuration" panel to change point sizes and opacity
  • Link to current view: Copy your current url
