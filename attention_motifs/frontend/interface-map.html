Head Analysis

Tools for understanding attention heads and their classifications

  • Classifications Page - Browse all head types with links to examples
  • Head Embedding Table - Compare embedding methods in 2D with SVG previews
  • Head Embedding Visualization - 3D exploration of head embeddings

AttentionPedia

The main interface connecting all analysis tools.

  • AttentionPedia - Explore heads with similar patterns and classifications

AttentionPedia serves as the central hub, allowing you to examine any attention head alongside similar (or un-similar!) heads, view multiple attention patterns side-by-side, and navigate to other analysis tools.

Pattern Analysis

Tools for examining individual attention patterns

  • Pattern Lens - Compare patterns across models and heads
  • Single Pattern View - Detailed view of individual attention patterns with their prompts
  • Pattern Embedding Visualization - 3D space of all attention patterns

Clustering

Tools for exploring hierarchical clustering of attention heads

  • Clustering Visualization - Dendrogram and grid view of cluster assignments
  • Cluster Trends - Cluster composition trends across models and layers
